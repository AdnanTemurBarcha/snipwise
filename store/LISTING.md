# Chrome Web Store listing kit — Snipwise Studio

Images in this folder are generated by `npm run store-assets` (drives the real build in Chrome). All are **24-bit PNG, no alpha**.

## Image checklist (per the Chrome Web Store docs)

| Asset | Size | Required | File |
|-------|------|----------|------|
| Store icon | 128×128 PNG (96×96 artwork + 16 px transparent padding) | Yes | `public/icons/icon128.png` (inside the extension ZIP) |
| Screenshots (1–5) | 1280×800 (or 640×400), JPEG or 24-bit PNG, full bleed, square corners | At least 1 | `screenshot-1…5-*.png` |
| Small promo tile | 440×280 | Optional (but listings with one rank higher) | `promo-small-440x280.png` |
| Marquee promo tile | 1400×560 | Optional (needed to be featured) | `promo-marquee-1400x560.png` |
| Promo video | YouTube link | Optional | — |

Upload order for screenshots: 1 → 5 (the first one is the hero shown in search).

## Short description (manifest, ≤132 characters)

Capture any page and edit it with layers, annotations, brushes, masks and filters. Export PNG or PDF. 100% local, no uploads.

## Detailed description

Plain text (the store does not render Markdown): copy the contents of [`description.txt`](description.txt) into the **Detailed description** field.

## Suggested listing fields

- **Category:** Productivity
- **Language:** English
- **Privacy policy URL:** https://github.com/AdnanTemurBarcha/snipwise/blob/main/privacy.md
- **Single purpose** (dashboard field): "Capture screenshots of web pages and edit and export them as images or PDFs."
- **Permission justifications:** see the table in `README.md` (`activeTab`/`scripting`: capture the page you invoked it on and show the crop overlay; `tabs`: take the screenshot and open the editor, PDF and docs tabs; `storage`: keep theme and saved presets). The exact text to paste is in `privacy-tab.txt`..

## Promo video (optional)

The Web Store takes a **YouTube link** (upload it as Unlisted or Public). A 45–60 second screen recording works well:

1. (0–5 s) Popup → **Full Page** → editor opens with the capture.
2. (5–18 s) Arrow + callout + numbered steps on the page.
3. (18–28 s) Blur an email address, then toggle the layer to show it's non-destructive.
4. (28–40 s) Select a photo layer: drop shadow, mask fade, an adjustment layer.
5. (40–50 s) **Export PDF** dialog with the live preview → Download.
6. (50–55 s) End card with the logo and "Snipwise Studio".

Keep it silent with on-screen captions, or add light music; no voice-over is needed.
